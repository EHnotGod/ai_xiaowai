# 原项目前端素材

本仓库保留原项目已有的 PNG、SVG 和字体文件及其原有用途。项目代码的 MIT 许可证不改变第三方图片、学校标识和字体的权利归属。

## 原文件

`frontend/src/assets/`、`frontend/public/logo.png` 及页面目录中的原始图片由项目所有者提供的前端 ZIP 恢复，后端默认头像 `backend/nailong.png` 由原后端 ZIP 恢复，均与原包逐文件校验。没有用新生成的品牌、图标或照片替换它们。

`frontend/src/assets/font/xiaobaiti.ttf` 为原包中的包图小白体，保留原文件。字体归其原权利人所有；[包图网字体页面](https://ibaotu.com/font/56.html)说明该字体可终身免费商用。字体不作为本项目自有 MIT 代码重新授权。

## 历史外链

原页面使用 `helloimg.com` 的形象图、校园点位照片及团队轮播图，以及第三方校园全景 iframe。外链地址保留，但部分历史图片已返回 404，不能因页面源码恢复而视为图片服务也已恢复。

原地图图片仍可从原地址取得。需要更换任何已失效素材时，请使用原文件或由项目所有者明确指定替代内容，不要把近似图像称作原图。
