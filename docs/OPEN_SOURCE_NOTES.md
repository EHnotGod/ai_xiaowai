# 历史项目整理说明

本仓库由两份历史压缩包整理而来，原项目开发时间为 **2024.11—2025.01**。本次整理保留前端页面和校园助手的主要使用流程，并修复影响本地复现和数据隔离的问题。

## 原始材料

| 压缩包 | 包含内容 | 整理方式 |
| --- | --- | --- |
| 前端 ZIP，约 40 MiB | Vue 源码、`node_modules`、`dist`、图片、字体 | 提取源码，依赖由锁文件安装，构建产物重新生成 |
| 后端 ZIP，约 91 MiB | 7 个 Python 文件、模型权重、知识文本、向量索引、服务器证书 | 拆分后端模块，以环境变量配置，提供可自行建立索引的公开示例 |

两份原始 ZIP 已按项目所有者要求删除，不进入 Git。它们不属于开源发布内容，不应作为 Release 附件上传。

原始包没有数据库建表 SQL、后端依赖清单和完整部署说明。整理版补充了数据库模型、安装依赖和启动说明；它不会自动导入旧服务器的数据库。

## 排除的内容

| 内容 | 原因及处理 |
| --- | --- |
| API 密钥、数据库密码、旧服务器配置 | 从可发布源码移除，使用 `.env`，示例不包含真实凭据 |
| TLS 私钥及证书 | 属于部署环境材料，不纳入版本控制 |
| 原始校园知识文本 | 再分发授权不明，使用新写的演示资料，使用者自行导入有权使用的内容 |
| m3e 权重、FAISS 索引和 pickle | 不直接发布模型及二进制索引，整理版索引可由文本重建 |
| 未附授权的字体、真人照片、校徽及第三方图片 | 从发布源码移除，界面使用系统字体和代码绘制的视觉元素 |
| Python 缓存、Node 依赖和构建产物 | 本地可重新生成，避免仓库体积膨胀 |

原始源码曾包含真实凭据。即使公开仓库不包含它们，也建议在对应服务端轮换仍有效的 API 密钥、数据库口令和服务器私钥。

## 整理版与原项目的区别

- 接口地址改为环境变量，前端可连接本地后端。
- 登录返回访问令牌，聊天历史和头像等资源按登录用户隔离；密码使用带盐哈希存储。此处只实现账户认证和资源归属检查，没有管理员/教师/学生角色权限系统。
- SQLite 用于快速本地运行，保留 MySQL 配置方式；启动时创建整理版的数据表。
- 不在模块导入时下载模型或重建索引，也不加载原包中的 pickle。
- 原始地图是地图图片、坐标标记及第三方全景嵌入，没有路径规划算法。整理版提供可配置地图入口，未配置时显示说明。
- 原第三方天气、联网搜索和旧图床不能直接视为仍可用的服务。整理版对未接入能力显示明确状态。
- 原关于页面中的“自我优化”“所有数据加密”“活动提醒”等表述缺少对应实现，不再作为当前功能承诺。

具体启动步骤、配置和接口约定以 [主 README](../README.md)、[前端说明](../frontend/README.md)及[后端说明](../backend/README.md)为准。

## 提交到 GitHub

本项目默认分支为 `main`。首次提交到新的 GitHub 仓库时，可在仓库根目录参考以下步骤：

```sh
python scripts/check_repository.py
git add .
git diff --cached --stat
git commit -m "chore: prepare AI Xiaowai for open source"
git remote add origin <你的 GitHub 仓库地址>
git push -u origin main
```

检查脚本检查 Git 已跟踪及未忽略的文件，只输出风险类型及位置，不输出凭据原文。它能拦住常见的误提交，不能代替对素材授权和任意格式凭据的人工检查。
