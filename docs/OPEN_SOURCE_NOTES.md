# 历史项目整理说明

原项目开发于 **2024.11—2025.01**。本仓库以项目所有者提供的前后端 ZIP 为准整理，保留原页面、素材、接口和后端业务流程，不引入替代应用架构。

## 原始内容与目录

| 原目录 | 仓库目录 | 保留内容 |
| --- | --- | --- |
| `前端/EHnew/` | `frontend/` | Vue 页面、原图片与字体、Pinia 状态、登录、聊天、地图、信息入口及关于页面 |
| `后端rag,mysql等/lannnngchain/` | `backend/` | 原七份 Python 源码、FastAPI 接口、MySQL 访问、m3e/FAISS 检索、模型工具选择、博查联网、天气和时间查询 |

工作区根目录的两个 ZIP 已按要求删除。原包的其他本机副本及本地恢复材料不进入 Git，也不作为 Release 附件发布。

## 整理范围

- 原前端模板、样式和业务脚本保持原实现；旧服务器 API 地址由 `VITE_API_BASE_URL` 配置。
- 原后端业务流程保持原实现；模型、博查、天气和数据库凭据通过后端环境变量配置。
- 本地模型、知识文本、索引和证书路径由配置指定，补充依赖与启动说明。
- 原 `lang.py` 在模块导入时重建索引，整理后改为显式执行 `python lang.py` 建库；原 FAISS、m3e 和 200 字分块 / 10 字重叠算法保持不变。
- 从原源码中的 SQL 整理出建表说明，供空数据库初始化，不视为旧数据库迁移。
- Node 依赖、构建产物、Python 缓存及编辑器文件不提交。

前端图片和字体保留原文件，来源与外链状态见[素材说明](ASSETS.md)。没有使用重新设计的界面取代原页面，也没有用新实现取代原后端。

## 不发布的本地材料

API 密钥、数据库密码、服务器私钥与证书、模型权重、旧 FAISS/pickle 索引和原校园知识文本不公开。原知识资料含电话、邮箱等内容，使用者应自行提供有权使用的资料。

原源码曾包含真实凭据，仍有效的凭据建议在对应服务端轮换。公开配置示例不包含原凭据。

## 原实现的范围

这是原校园项目的开源整理版。原登录返回布尔结果，历史与头像接口使用用户名等字段，没有新增 Bearer、角色权限或替代数据库层。原地图是图片热点和第三方全景；原信息页是校园服务链接。不能据此声称已有完整权限体系、路线规划、个人课表数据库或自动训练系统。

保留这些原实现不代表已完成生产部署加固。需要改变业务、安全模型或页面设计时，应另有明确需求，不能把这种改写混入目录整理。

原天气、时间与联网调用保留在源码中。没有服务密钥时需在本地配置，而不是通过删除调用或隐藏原入口来处理。

## 验证与提交

前端执行 `npm ci` 和 `npm run build`；后端语法检查不执行模块导入，也不调用模型或数据库。完整运行需要配置 MySQL、m3e 模型、校园知识文本及相应 API 服务。

在根目录提交前执行：

```sh
python scripts/check_repository.py
git add .
git diff --cached --stat
git commit -m "chore: organize original project"
git push
```

检查脚本会检查工作树和暂存版本，报告风险位置，不输出凭据原文。它用于发现常见误提交，不能证明不存在任意格式的秘密。
